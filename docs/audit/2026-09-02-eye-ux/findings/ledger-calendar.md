# ledger-calendar（予約台帳）— 実機監査所見

環境: `vite preview` :4310（使い捨て D1 + seed）／Playwright Chromium 1194×834（iPad 横）／
時刻を JST 2026-08-27 11:08 に固定。実装は `src/web/ledger/`。

## 監査した画面・経路
- 予約台帳 タイムテーブル（担当者軸）／設備・場所軸／予約リスト
- 予約ブロックの詳細ポップオーバー、ウォークイン札、休憩帯、担当が未定レーン、ご来店お待ち行
- 日付移動（前の日／本日／次の日）、+3日・+60日、日曜（2026/8/30）
- 128 個の「押せそうな要素」の総当たりクリック／ダブルクリック
- 横スクロール・縦スクロール・キーボード移動（矢印キー）・フォーカス
- 画面外にはみ出す要素の実測

## 総評 — **38 / 100**（LEDGER-07 撤回により +3）

台帳としての「見る」機能は形になっているが、**「触る」機能がほぼ存在しない**。
1 日ぶんの盤面の右 272px（17:00〜18:30 の 4 列・21 セル）が **iPad の画面外に出たまま
スクロールの手がかりも無く**、横に送ると今度は**担当者名の列が消える**。
盤面の 69 個の空き枠は**クリックしても意図的に何も起こさない実装**になっており、
台帳から予約を作る・動かす・伸ばすという、予約台帳がいちばんやるべき操作が 1 つも無い。
オーナーの「予約枠をクリックしても何も起きない」は正しく、しかも原因は 1 つではない。

## 所見一覧

### LEDGER-01 営業終了までの 2 時間半が画面の外にあり、スクロールの手がかりが無い
- **重大度**: **S1**
- **画面**: 予約台帳 タイムテーブル（担当者軸・設備軸とも）
- **再現**: 台帳を開く（銀座店・2026/8/27）。営業は 10:00–19:00 だが、画面に見えるのは 16:30 まで。
- **いま起きること**: 盤の実寸 1390px に対しビューポート 1194px。実測で
  `columnheader` の **17:00 / 17:30 / 18:00 / 18:30** と **21 個の `gridcell`** が
  `getBoundingClientRect().right > window.innerWidth`。
  佐藤 美咲 の 17:00・17:30 には実際にご予約が入っているが、開いた瞬間には**存在すら見えない**。
  スクロール可能な親（`overflow-x-auto`, scrollWidth 1390 / clientWidth 1118）はあるが、
  **スクロールバーも影もフェードも矢印も無い**ので、続きがあることが分からない。
- **あるべき姿**: 1 画面に営業時間全部を収めるか（列幅を可変にする／30 分刻みを圧縮する）、
  少なくとも「まだ続きがある」ことを端のグラデーションと影で示し、
  現在時刻付近へ自動スクロールし、時間帯ジャンプ（午前／午後／夕方）を置く。
  Google カレンダーもトレタも、開いた瞬間に「今」が中央に来る。
- **根拠**: `src/web/ledger/Timetable.tsx:203`（`role="grid"` の幅指定）、
  スクリーンショット `shots/ledger/01-timetable.png`（16:30 で切れている）
- **直し方の案**: ①盤の親に `overflow-x-auto` があるので、両端に `mask-image` かグラデーションの影を出す。
  ②初期表示で `serverNow` の列が見える位置へ `scrollIntoView`。
  ③列幅を `minmax()` にして、営業時間が短い日は全列を画面に収める。
- **見積り**: M

### LEDGER-02 横に送ると担当者名の列が一緒に流れて消える
- **重大度**: **S1**
- **画面**: 予約台帳 タイムテーブル
- **再現**: 盤の上でホイール／二本指スワイプで右へ送る。
- **いま起きること**: `rowheader`（担当者名）の `position` は **`static`**。scrollLeft 272 で
  名前列の left が **-196px** になり、画面から完全に消える。
  スクリーンショット `shots/ledger/08-scrolled-right.png` では、17:00 のご予約は見えるが
  **それが誰の列なのか判別できない**。時刻の見出し行も同様に固定されていない。
- **あるべき姿**: 名前列は `position: sticky; left: 0`、時刻の見出し行は `sticky; top: 0`。
  カレンダー UI の最低条件で、Google カレンダーもトレタも例外なくそうしている。
- **根拠**: `src/web/ledger/Timetable.tsx:307`（`role="rowheader"` に position 指定が無い）、
  `shots/ledger/08-scrolled-right.png`
- **直し方の案**: `rowheader` に `sticky left-0 z-10 bg-surface`、見出し行に `sticky top-0 z-10` を付ける。
  交差する左上のセルだけ `z-20`。
- **見積り**: S

### LEDGER-03 空き枠をクリックしても何も起きない（盤面の 69 セルが死んでいる）
- **重大度**: **S1**
- **画面**: 予約台帳 タイムテーブル
- **再現**: 「佐藤 美咲 10:00 空いています」のセルをクリック／ダブルクリックする。
- **いま起きること**: **何も起きない**。総当たりの実測結果:

  | 押したもの | 個数 | 結果 |
  |---|---|---|
  | 予約ブロック（クリック） | 8 | ✅ 詳細が開く |
  | 予約ブロック（ダブルクリック） | 8 | ❌ 何も起きない |
  | **空き枠セル（「◯◯ 空いています」）** | **69** | **❌ 何も起きない** |
  | 休憩の帯 | 3 | ❌ 何も起きない |
  | 行ヘッダ（担当者名） | 6 | ❌ 何も起きない |
  | 列ヘッダ（時刻） | 19 | ❌ 何も起きない |
  | ご来店お待ちの行 | 1 | ❌ 押せない |

  コード上も意図的な no-op である:
  ```ts
  // Timetable.tsx:164
  function press(segment, rowIndex) {
    setActive({ row: rowIndex, column: segment.columnIndex })
    if (segment.kind !== 'entry') { setHeld(null); onSelectEntry?.(null); return }  // ← 空き枠はここで終わり
  ```
  さらに `gridcell` は `<div>` で `cursor: pointer` を持たないため、
  **押せるセルと押せないセルが見た目で区別できない**（128 要素中、`cursor:pointer` は 0 件）。
- **あるべき姿**: 空き枠をタップ＝その担当・その時刻で新規予約を作り始める。
  Google カレンダーもトレタも、空いているところを押すのが新規作成の第一導線である。
  押せないもの（営業時間外・休憩）は押せない見た目にする。
- **根拠**: `src/web/ledger/Timetable.tsx:164-176`, `Timetable.tsx:534-546`,
  `shots/ledger/01-timetable.png`
- **直し方の案**: `press()` の非 entry 分岐で、`available` なセルなら
  「この時間で予約を取る」確認チップ or 予約作成へ遷移（日時・担当・場所を前埋め）。
  `available` なセルに `cursor-pointer` と押下時の背景変化を付け、
  `outside_hours` / `break` は `aria-disabled` にする。
- **見積り**: M

### LEDGER-04 台帳から予約を動かす・伸ばす手段が一切無い（ドラッグ非対応）
- **重大度**: **S1**
- **画面**: 予約台帳 タイムテーブル
- **再現**: 予約ブロックを掴んで別の時間・別の担当へ動かそうとする。
- **いま起きること**: `Timetable.tsx` に `onPointerDown` / `onMouseDown` / `onDragStart` が
  **1 つも無い**（あるのは `onClick` と `onKeyDown` だけ）。
  ドラッグでの移動も、端をつまんでの所要時間変更も存在しない。
  時間を変えるには 詳細 →「変更する」→ 別画面の日時選択、という遠回りしか無い。
- **あるべき姿**: 帯をドラッグして担当・時刻を変える。端をつまんで所要を伸縮する。
  ドラッグ中はゴーストと吸着先の時刻をリアルタイムに出し、Esc で取り消せる。
  置けない場所には理由を出す（`booking/slot-drag.ts` の `blockedText` が既にその文言を持っている）。
- **根拠**: `src/web/ledger/Timetable.tsx` 全域（ポインタ系ハンドラ 0 件）、
  `src/web/booking/slot-drag.ts`（予約作成側にはドラッグの純関数がある＝台帳側だけ未実装）
- **直し方の案**: `booking/slot-drag.ts` の `snapToCell` / `columnSpan` / `blockedText` を
  台帳でも再利用し、`Timetable` に pointer ドラッグを実装する。
  変更確定は既存の変更 API（楽観ロック付き）へ、失敗したら元の位置へ戻す。
- **見積り**: L

### LEDGER-05 30 分幅の予約にお客様のお名前が出ない
- **重大度**: **S1**
- **画面**: 予約台帳 タイムテーブル
- **再現**: 佐藤 美咲 の 17:00 / 17:30 の帯を見る。
- **いま起きること**: 帯に **「17:00」という時刻だけ**が出て、お名前もご用件も出ない。
  コード上「30分 1 列の文字予算はおよそ 6 字しかない」として、狭い帯は
  ご用件を落とす実装（`Timetable.tsx:501`）。結果として、
  **1 日の予約のうち 30 分枠のものは誰の予約か台帳から読めない**。
- **あるべき姿**: 名字だけでも必ず出す（「松本 様」は出ている＝出し分けが不安定）。
  幅が足りないなら 2 行にする・フォントを詰める・省略記号にする。名前が消えるのは最後の手段。
- **根拠**: `src/web/ledger/Timetable.tsx:488-505`, `shots/ledger/08-scrolled-right.png`
- **直し方の案**: 帯の最小内容を「時刻＋名字＋様」に固定し、削るのはご用件・回数バッジ・出どころから。
- **見積り**: S

### LEDGER-07 【撤回】絞り込みが実装されているのに画面に出ていない
- **重大度**: ~~S2~~ → **撤回（2026-09-03）**
- **撤回の理由**: 事実と異なっていた。絞り込みは `ReservationList.tsx:190-213` に実装されており、
  「すべて 12件／これから 0件／確認待ち 1件」のチップが `aria-pressed` つきで動作する。
  監査時に予約リスト表示を開かずタイムテーブル表示だけを見て「UI が無い」と誤って断じた。
- **ただし残る論点**: この絞り込みは「予約台帳の 3 つ目の表示モードの中」にしかない。
  受付に立つアルバイトがいちばん欲しい「これから来る人」の一覧が、
  台帳 → 予約リスト → チップ、という 3 手の奥にある。置き場所の問題として
  `findings/reception.md` RECEP-02 と合わせて扱う。

### LEDGER-08 日表示しか無い（週・月が無い）
- **重大度**: S2
- **画面**: 予約台帳
- **再現**: 「次の日」を 60 回押す → 2026/10/26 まで行けるが、常に 1 日ずつ。
- **いま起きること**: 表示は 1 日単位のみ。日付ピッカー／カレンダー／週表示／月表示が無い。

  週表示は空き状況を面で見るための必須機能で、電話口で「来週なら何曜が空いてますか」に答えられない。
- **根拠**: `src/web/ledger/LedgerScreen.tsx`（`shiftDate` による ±1 日のみ）、`shots/ledger/10-plus60days.png`
- **直し方の案**: 日付の帯をタップでカレンダーポップオーバー、ツールバーに 日/週/月 のセグメント。
- **見積り**: L

### LEDGER-10 押せるものと押せないものが見た目で区別できない
- **重大度**: S2
- **画面**: 予約台帳 全域
- **いま起きること**: 盤面の 128 要素すべてが `cursor: default`。予約ブロックは押せるのに
  押せそうに見えず、空き枠は押せないのに同じ見た目。
  ホバーしても何も変わらない（アプリ全体で `hover:` の使用は **0 件**）。
  押した瞬間の反応（`active:`）も無い。
- **あるべき姿**: 押せるものに `cursor: pointer` とホバー・プレスの状態変化。
- **根拠**: 実測（`cursor:pointer` 0 件）、`src/web` 全体の `hover:` grep 0 件
- **直し方の案**: 予約ブロックに `cursor-pointer` と押下時の縮み、空き枠には
  「＋」の薄いゴーストをホバー時に出す（＝ここを押すと予約が作れる、という語彙）。
- **見積り**: S

### LEDGER-16 台帳全体にモーションが 1 つも無い
- **重大度**: S2
